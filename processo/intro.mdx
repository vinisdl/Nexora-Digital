# Processo Nexora SDD

Este é o **Processo Organizacional de Desenvolvimento de Software da Nexora Digital**. Ele vale para todas as equipes e todos os produtos (Nexora Sales, Flow e Analytics), além de customizações e integrações para clientes.

A ideia central é **Spec-Driven Development com OpenSpec**: a especificação vem antes do código, mora no Git junto do código e é a fonte da verdade sobre o que o sistema faz.

:::info[Release 1.0]
Esta é a primeira versão oficial do processo, validada por revisão cruzada e por um exemplo ponta a ponta. Veja o que mudou no [changelog](/docs/sobre/changelog) e como ela foi validada em [Validação](/docs/validacao).
:::
