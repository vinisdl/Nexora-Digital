# Template · Work item (AF01)

Usado na [Entrada](/docs/fases/entrada). No Azure DevOps, os campos marcados com * são obrigatórios para mover o item para `Pronto`.

```markdown
Título*: [Produto] Verbo + resultado (ex.: [Sales] Aplicar desconto antes do frete)

Tipo*: User Story | Bug
Categoria*: Pequena | Média | Grande | Crítica
Solicitante*: nome, cliente ou área

## Problema*
O que acontece hoje e quem é afetado.

## Valor*
O que melhora para o cliente ou para a Nexora se isso for feito.

## Critério de aceite*
Em linguagem de negócio, verificável pelo PO:
- Dado ..., quando ..., então ...

## Links
- Conversa de origem (Teams, e-mail, chamado)
- Change: preenchido na Especificação (campo Change ID)
```
