# Template · tasks.md (AF05)

Usado na [A2.5](/docs/fases/especificacao) e executado na [Construção](/docs/fases/construcao). Obrigatório em todas as categorias.

```markdown
# Tasks: <id>-<slug>

## 1. Implementação
- [ ] 1.1 <tarefa pequena e verificável> (estimativa: 2h)
- [ ] 1.2 ...

## 2. Testes dos cenários
- [ ] 2.1 Teste: Scenario "Cliente com desconto"
- [ ] 2.2 Teste: Scenario "Cliente sem desconto"

## 3. Entrega
- [ ] 3.1 Atualizar documentação de uso, se houver
- [ ] 3.2 openspec archive <id>-<slug>
```

:::tip
Toda task de teste cita o nome exato do cenário. Assim o QA confere a cobertura só lendo o tasks.md.
:::
