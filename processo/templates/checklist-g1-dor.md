# Checklist G1 · Definition of Ready

Gate entre **Entrada** e **Especificação**. Dono: **PO**. Sem G1, o work item não sai de `Novo`.

```markdown
G1 · Definition of Ready (AB#<id>)

- [ ] O problema está descrito: o que acontece hoje e quem é afetado
- [ ] O valor está claro: o que melhora se isso for feito
- [ ] O solicitante está identificado (pessoa, cliente ou área)
- [ ] Há critério de aceite em linguagem de negócio, verificável pelo PO
- [ ] A categoria está definida (pequena, média, grande ou crítica)
- [ ] A prioridade no backlog está definida
- [ ] Links da conversa de origem anexados (Teams, e-mail, chamado)
```

| Item | Verificação |
|---|---|
| Problema, valor, solicitante, critério de aceite, categoria | Automática: campos obrigatórios para o estado `Pronto` no Azure DevOps |
| Qualidade do critério de aceite | Manual: PO |
