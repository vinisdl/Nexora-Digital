# Checklist G4 · Definition of Done

O "Done" único da Nexora. Vale para todas as equipes e todas as categorias.

```markdown
G4 · Done (AB#<id>)

- [ ] Todos os cenários da spec têm teste automatizado
- [ ] Todos os testes dos cenários passam no pipeline
- [ ] Code review aprovado
- [ ] Aceite do PO registrado no work item
- [ ] Change arquivada (openspec archive): a spec oficial está atualizada
- [ ] Deploy feito pelo pipeline e release notes geradas
```

:::info[Done = 4 condições]
Cenários da spec passando + code review + aceite do PO + change arquivada. Se faltar uma, não está pronto.
:::
