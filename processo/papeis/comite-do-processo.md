# Comitê do Processo

**Missão:** ser o dono do processo. O processo também é um produto: tem versão, changelog e melhorias.

| | |
|---|---|
| **Responde por** | Versionar o processo, conduzir a retrospectiva, aprovar melhorias |
| **Aprova (A)** | Melhoria contínua (A6.1 a A6.3) |
| **Artefatos** | Ata da retrospectiva (AF12), changelog do processo |
| **Composição sugerida** | Um representante de cada papel (PO, Dev, TL, QA, DevOps) e o gestor de engenharia |
