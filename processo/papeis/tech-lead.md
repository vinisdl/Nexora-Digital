# Tech Lead

**Missão:** garantir que a solução seja viável, coerente com a arquitetura e com qualidade verificável.

| | |
|---|---|
| **Responde por** | Categoria, viabilidade técnica, aprovação da spec (G3), code review |
| **Aprova (A)** | Revisão (G3) e Construção |
| **Artefatos** | design.md (aprova), spec oficial (AF09) |

## Atividades

- [A1.2 Classificar a categoria](/docs/fases/entrada)
- [A3.3 Revisar a viabilidade técnica](/docs/fases/revisao) · aprovador do G3
- [A4.3 Code review](/docs/fases/construcao)
- [A5.2 Arquivar a change](/docs/fases/entrega) (aprova)

Nas mudanças **grandes**, os Tech Leads de todas as equipes envolvidas revisam a spec.
