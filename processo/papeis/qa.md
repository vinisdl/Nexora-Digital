# QA

**Missão:** ser o dono dos cenários. Se um comportamento não tem cenário, ele não foi especificado; se o cenário não tem teste, ele não foi verificado.

| | |
|---|---|
| **Responde por** | Qualidade dos cenários WHEN/THEN e dos testes automatizados |
| **Aprova (A)** | A4.2 Automatizar os cenários |
| **Artefatos** | Testes dos cenários (AF08) |
| **Gates** | Guardião do G2 (spec completa) e do G4 (cenários passando) |
