# Segurança

**Missão:** proteger os clientes regulados e garantir a trilha de auditoria. Atua **só nas mudanças críticas**.

| | |
|---|---|
| **Responde por** | Revisão de segurança (AF07), com o [checklist de segurança](/docs/templates/checklist-seguranca) |
| **Quando** | [A3.3 Revisar a viabilidade técnica](/docs/fases/revisao), categoria crítica |
| **Garante** | Que a change arquivada permita provar quem pediu, quem aprovou e quando entrou em produção |
| **Também aprova** | O deploy em produção das changes críticas ([Gerência de configuração](/docs/governanca/gerencia-de-configuracao)) |
