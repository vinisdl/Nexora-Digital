# Desenvolvedor (com IA)

**Missão:** transformar a demanda em spec, tasks e código, nessa ordem.

| | |
|---|---|
| **Responde por** | Abrir a change, escrever spec e tasks, implementar, arquivar a change |
| **Executa (R)** | Especificação, Construção, archive na Entrega |
| **Artefatos** | proposal.md, delta da spec, design.md, tasks.md, PRs, código |
| **Ferramentas** | GitHub, OpenSpec, assistente de IA |

## Atividades

- [A2.1 a A2.5](/docs/fases/especificacao): abrir a change, proposal, delta da spec, design e tasks
- [A3.1 Abrir o PR da spec](/docs/fases/revisao)
- [A4.1 Implementar](/docs/fases/construcao) · [A4.3 Code review como par](/docs/fases/construcao)
- [A5.2 Arquivar a change](/docs/fases/entrega)

:::info[Uso de IA]
A IA pode rascunhar a spec, os cenários e o código. O Dev revisa tudo e responde pelo resultado. A IA nunca é R nem A.
:::
