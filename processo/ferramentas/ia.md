# Assistente de IA

**Papel no processo:** acelerar a escrita, nunca decidir.

| Pode | Não pode |
|---|---|
| Rascunhar proposal, delta da spec e cenários | Ser R ou A de qualquer atividade |
| Sugerir casos de borda para o QA avaliar | Aprovar PR ou passar gate |
| Gerar código a partir do tasks.md | Mudar a spec sem PR |
| Resumir uma conversa do Teams para virar alteração na change | |

:::tip[Regra]
Quem usa a IA responde pelo que ela produziu. Todo conteúdo gerado passa pela mesma revisão que um conteúdo escrito à mão.
:::
